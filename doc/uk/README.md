Керування та моніторинг ставкових насосів **OASE AquaMax Eco Titanium** через **OASE Garden Controller Cloud (EGC)** — локально та через хмару.

## Відмова від відповідальності

Це **неофіційний спільнотний проєкт**. Він **жодним чином не пов'язаний з OASE GmbH, не схвалений і не підтримується нею**. «OASE», «AquaMax» та пов'язані назви продуктів є торговими марками OASE GmbH і використовуються тут виключно для опису сумісності з пристроями. Протокол зв'язку було проаналізовано незалежно — використовуйте цей адаптер на власний ризик.

## Підтримуване обладнання

| Пристрій | Артикул | Роль |
| --- | --- | --- |
| OASE Garden Controller Cloud (EGC) | 55317 | Шлюз (`GatewayCloud`) |
| OASE AquaMax Eco Titanium | 73656 | Ставковий насос (`GardenPump`) |

## Можливості

- Увімкнення та вимкнення кожного насоса
- Налаштування швидкості насоса від 0 до 100 %
- Зчитування телеметрії в реальному часі: потужність (Вт), оберти двигуна (об/хв), температура (°C) та напруга мережі (В)
- Перегляд стану з'єднання та пристрою
- Насоси зберігають назви, які ви їм дали в застосунку OASE

## Хмарна автентифікація

Хмара OASE використовує **Azure AD B2C** (`account.oase.com`). Адаптер автентифікується за допомогою механізму refresh-token: один раз перехопіть refresh-токен під час входу в застосунку OASE та вставте його в налаштування адаптера (зберігається в зашифрованому вигляді). **Пароль вашого облікового запису ніколи не вводиться в адаптер і не зберігається ним.**

## Налаштування

| Параметр | Опис |
| --- | --- |
| Режим з'єднання | `cloud` / `local` |
| Інтервал опитування | Інтервал опитування в секундах (за замовчуванням 30) |
| Хмарний refresh-токен | Перехоплений під час входу в застосунку OASE (зберігається в зашифрованому вигляді) |
| IP контролера | IP-адреса шлюзу EGC (локальний режим) |
| Пароль пристрою | Пароль пристрою для локальної автентифікації (зберігається в зашифрованому вигляді) |
| Адреса/порт прив'язки | Локальний TLS-сервер, до якого контролер підключається у зворотному напрямку |
