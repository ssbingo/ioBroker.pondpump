Управление и мониторинг прудовых насосов **OASE AquaMax Eco Titanium** через **OASE Garden Controller Cloud (EGC)** — локально и через облако.

## Отказ от ответственности

Это **неофициальный проект сообщества**. Он **никак не связан с компанией OASE GmbH, не одобрен и не поддерживается ею**. «OASE», «AquaMax» и связанные названия продуктов являются товарными знаками OASE GmbH и используются здесь исключительно для описания совместимости с устройствами. Протокол обмена данными был проанализирован независимо — используйте этот адаптер на свой страх и риск.

## Поддерживаемое оборудование

| Устройство | Артикул | Роль |
| --- | --- | --- |
| OASE Garden Controller Cloud (EGC) | 55317 | Шлюз (`GatewayCloud`) |
| OASE AquaMax Eco Titanium | 73656 | Прудовый насос (`GardenPump`) |

## Возможности

- Включение и выключение каждого насоса
- Установка скорости насоса от 0 до 100 %
- Чтение телеметрии в реальном времени: мощность (Вт), скорость двигателя (об/мин), температура (°C) и сетевое напряжение (В)
- Отображение состояния соединения и устройства
- Насосы сохраняют имена, которые вы задали им в приложении OASE

## Облачная аутентификация

Облако OASE использует **Azure AD B2C** (`account.oase.com`). Адаптер аутентифицируется с помощью гранта refresh-token: один раз перехватите токен обновления при входе в приложение OASE и вставьте его в настройки адаптера (хранится в зашифрованном виде). **Пароль вашей учётной записи никогда не вводится в адаптер и не хранится в нём.**

## Настройка

| Параметр | Описание |
| --- | --- |
| Режим соединения | `cloud`, `local` или `both` |
| Интервал опроса | Интервал опроса в секундах (по умолчанию 30) |
| Облачный токен обновления | Перехваченный при входе в приложение OASE (хранится в зашифрованном виде) |
| IP-адрес контроллера | IP-адрес шлюза EGC (локальный режим) |
| Пароль устройства | Пароль устройства для локальной аутентификации (хранится в зашифрованном виде) |
| Адрес привязки / порт | Локальный TLS-сервер, к которому контроллер устанавливает обратное соединение |
